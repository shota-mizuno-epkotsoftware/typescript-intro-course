PHP でプログラミングの基礎を学んだ人が、自習で TypeScript のコードを読めるようになり、フロントエンド（画面の見た目と動き）のコードを扱えるようになるための教材です。

メインは本編です。PHP の基礎があやふやな人は、先に基礎編から始めます。本編の後は、オプションの実践編で、小さなアプリのコードを読みます。その後に、同じアプリの React 版を読む React 編（オプション）もあります。実践編と React 編は、それぞれ 1 ページです。

講座で学ぶ技術どうしのつながりは、学ぶ技術の関係 で先に見渡せます。

前提

  • PHP で変数・条件分岐・ループ・関数・配列を一度は学んだ（今どこまで使えるかは、下の「どこから始めるか」で確かめます）
  • JavaScript の経験は問わない
  • ターミナルでコマンドを実行できる
  • HTML のタグ・属性・class/id が分かる（本編 第10章で使います）
  • Git の基本操作（clone・commit・diff など）ができる

どこから始めるか

本編は、PHP の基礎を自分で使える人に向けて書いてあります。次の 5 問（PHP のコードを読む問題）は、今の自分がどのあたりにいるかをつかむための目安です。試験ではないので、気軽に解いてください。

5 問を開く

紙かメモに答えを書いてから、「答えと目安」を開きます。調べたり、実行したりせずに答えます。

問題 1：次のコードを実行すると、下の警告が出ます。警告は何と言っていますか（日本語で）。何行目をどう直せばよいですか。

<?php
$total = 0;
$total = $total + 500;
echo $totl;
Warning: Undefined variable $totl in /…/check.php on line 4

問題 2：何が表示されますか。

<?php
function grade($score) {
    if ($score >= 80) {
        return "A";
    } elseif ($score >= 60) {
        return "B";
    }
    return "C";
}
echo grade(80) . grade(59) . grade(60);

問題 3：何が表示されますか。

<?php
$prices = [120, 3000, 80];
$sum = 0;
foreach ($prices as $price) {
    $sum += $price;
    echo $sum . " ";
}

問題 4：何が表示されますか。

<?php
$items = [
    ["name" => "ノート", "price" => 120],
    ["name" => "ペン", "price" => 80],
];
echo $items[1]["name"] . ": " . count($items);

問題 5：何が表示されますか。

<?php
function addShipping($price) {
    $price = $price + 500;
    return $price;
}
$base = 1000;
$result = addShipping($base);
echo $base . " / " . $result;
答えと目安
問題 答え 外れたときに読む基礎編の章
1 「4 行目の $totl という変数はない」と言っている。$total のつづりを間違えているので、echo $total; に直す（警告の意味と、つづりの間違いの両方を言えたら正解） 第3章 エラーを読む
2 ACB（80 は A、59 は C、60 は B。return を実行すると、そこで関数が終わる） 第4章 条件分岐、第6章 関数
3 120 3120 3200（1 回ごとに足した後の合計を表示する） 第5章 配列と繰り返し
4 ペン: 2（番号は 0 から数える。count は要素の数） 第5章 配列と繰り返し、第8章 オブジェクト（PHP の連想配列にあたるもの）
5 1000 / 1500（呼び出すと $base の値がコピーされて $price に入る。関数の中で変えたのはコピーなので、外の $base は変わらない） 第6章 関数、第7章 関数を組み合わせる

迷わずに答えられた問題を数えて、入口の目安にします。

  • 4 問以上：本編 第0章 からが目安です。外れた問題・迷った問題があれば、表の基礎編の章を先に読んでおくと安心です。そのときも、準備は本編 第0章の 0.1・0.2 で済ませてから読みます。
  • 3 問以下：基礎編 第0章 からが目安です。基礎編は、知っている章を飛ばして進めても構いません。

どちらから始めても、途中で入口を変えて構いません。本編で詰まったときに戻る基礎編の章は、本編 第0章 の「詰まったとき」にあります。

はじめ方

教材の用意（git clone と npm install）は、始める編の第0章で行います。基礎編からなら 基礎編 第0章、本編からなら 本編 第0章 です。同じフォルダで、最後まで進めます。

本文は、HTML 版で読むのがおすすめです。予測を書き込む欄やチェックリストを使えます。教材のフォルダの html/index.html をブラウザで開きます（Finder やエクスプローラーでダブルクリック）。

基礎編 オプション（本編の前） PHP で一度学んだ基礎を、JavaScript で手を動かして確かめ直す
本編 メイン TypeScript の文法と型の考え方。最後にブラウザの画面を動かす
実践編 オプション（本編の後） 1 ページで、小さな Web アプリのコードを読み解き、3 つの改修をする

進む順は、本編（12 章）→ 実践編（1 ページ）→ React 編（1 ページ）です。実践編と React 編には、同じ内容を 7 章に分けて詳しく読む「詳細版」もあります。読むかどうかは任意です。
