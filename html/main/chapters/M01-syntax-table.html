同じ処理を並べて見る

制御構文や関数の形は、PHP とよく似ています。変数、連想配列、文字列の書き方は違います。

次の 2 つは、どちらも買い物の合計を計算して表示するプログラムです。

<?php
function subtotal(int $price, int $quantity): int {
    return $price * $quantity;
}

$items = [
    ["name" => "ノート", "price" => 120, "quantity" => 3],
    ["name" => "ペン", "price" => 80, "quantity" => 0],
];
$total = 0;
foreach ($items as $item) {
    if ($item["quantity"] === 0) {
        continue;
    }
    $total += subtotal($item["price"], $item["quantity"]);
}
echo "合計: {$total}円\n";
function subtotal(price: number, quantity: number): number {
  return price * quantity;
}

const items = [
  { name: "ノート", price: 120, quantity: 3 },
  { name: "ペン", price: 80, quantity: 0 },
];
let total = 0;
for (const item of items) {
  if (item.quantity === 0) {
    continue;
  }
  total += subtotal(item.price, item.quantity);
}
console.log(`合計: ${total}円`); // → 合計: 360円
違い 見る表
型は price: number のように名前の後ろに書く 1.5
連想配列は { name: "ノート" } のオブジェクトで書き、item.price で取り出す 1.7
foreach は for (const item of items) 1.4
変数は let / const で宣言する 1.1
値の埋め込みはバッククォートの ${} 1.2

1.1 変数と出力

値を表示する

PHP
echo $x;/var_dump($x);
TS
console.log(x);

コメント

同じ

PHP
// 1行//* 複数行 */
TS
// 1行//* 複数行 */

変数を作る

$ は付けない。初めて使うときに let か const で宣言する

PHP
$count = 0;
TS
let count = 0;

再代入しない変数

基本は const を使い、再代入が必要なときだけ let。const が何を禁止するかは第4章

PHP
const TAX_RATE = 0.1;
TS
const taxRate = 0.1;

値がない

値がないことを表す値が2種類ある（第2章・第6章）

PHP
null
TS
null/undefined

1.2 文字列と数値

文字列をつなぐ

+ は数値の足し算と同じ記号。数値と文字列を組み合わせたときの動きは第2章

PHP
"合計: " . $total
TS
"合計: " + total

文字列に値を埋め込む

バッククォートで囲む（テンプレートリテラル。第2章）。" と ' は埋め込みをしない

PHP
"Hello, {$name}"
TS
`Hello, ${name}`

文字列の長さ

全角も半角も 1 文字は 1（strlen のようなバイト数ではない）。絵文字などは、1 文字でも 2 以上になる

PHP
mb_strlen($s)
TS
s.length

大文字にする

文字列の操作は 値.メソッド() の形で書く（メソッドは、値に付いている関数）

PHP
strtoupper($s)
TS
s.toUpperCase()

含まれるか

PHP
str_contains($s, "a")
TS
s.includes("a")

分割・連結

PHP
explode(",", $s)/implode(",", $a)
TS
s.split(",")/a.join(",")

数値に変換する

変換できないと NaN になる（第2章）。(int) と違い、小数は切り捨てない

PHP
(int)$s/intval($s)
TS
Number(s)

型を調べる

結果の文字列が違う（第2章）

PHP
gettype($x)
TS
typeof x

1.3 比較と条件分岐

等しい・等しくない

同じ。== は使わない（型を変換するルールが PHP と違うため）。配列やオブジェクトどうしの比較は第4章 4.4

PHP
===/!==
TS
===/!==

かつ・または・否定

書き方は同じ。|| の動きの違いは第6章 6.2

PHP
&&/||/!
TS
&&/||/!

条件分岐

elseif は else if と離して書く

PHP
if (...) { } elseif (...) { } else { }
TS
if (...) { } else if (...) { } else { }

三項演算子

書き方は同じ。条件にしたときの扱いは第6章の問題 1

PHP
$a ? $b : $c
TS
a ? b : c

null なら別の値

同じ（第6章）

PHP
$a ?? "なし"
TS
a ?? "なし"

値で分岐

書き方は同じ。PHP の switch は == で比べるが、TypeScript は === で比べる（型も一致が必要）

PHP
switch ($x) { case 1: ... break; }
TS
switch (x) { case 1: ... break; }

1.4 ループ

回数を決めて繰り返す

PHP
for ($i = 0; $i < 3; $i++) { }
TS
for (let i = 0; i < 3; i++) { }

配列の要素を順に

of を使う。for...in は別物（キーを回る）なので配列には使わない

PHP
foreach ($items as $item) { }
TS
for (const item of items) { }

番号と要素を順に

要素が先、番号が後。forEach の中では break・continue を使えない。=> の書き方は第3章

PHP
foreach ($items as $i => $item) { }
TS
items.forEach((item, i) => { });

条件の間繰り返す

同じ

PHP
while ($n > 0) { }
TS
while (n > 0) { }

抜ける・次へ

同じ

PHP
break;/continue;
TS
break;/continue;

1.5 関数

関数を作る

型は名前の後ろに : で書く（第2章）

PHP
function add(int $a, int $b): int {
return $a + $b;
}
TS
function add(a: number, b: number): number {
return a + b;
}

引数の初期値

同じ

PHP
function greet($name = "ゲスト") { }
TS
function greet(name = "ゲスト") { }

名前のない関数

アロー関数（第3章）

PHP
fn($x) => $x * 2
TS
(x: number) => x * 2

1.6 配列

配列を作る

PHP
$a = [1, 2, 3];
TS
const a = [1, 2, 3];

要素を取り出す

範囲外は undefined（エラーにならない）

PHP
$a[0]
TS
a[0]

要素の数

PHP
count($a)
TS
a.length

末尾に追加

const の配列にも追加できる（止めるのは再代入だけ）。配列を代入したときの動きとあわせて第4章

PHP
$a[] = 4;/array_push($a, 4);
TS
a.push(4);

含まれるか

PHP
in_array(2, $a, true)
TS
a.includes(2)

変換・絞り込み

第7章

PHP
array_map(...)/array_filter(...)
TS
a.map(...)/a.filter(...)

1.7 連想配列とオブジェクト

PHP の連想配列は、TypeScript では主にオブジェクトで表します。オブジェクトの name や age のような、名前の付いた値をプロパティと呼びます。

作る

キーは普通 " なしで書く。user-id のように - を含むキーは、引用符で囲む（{ "user-id": 1 }）。オブジェクトの型の書き方は第4章（詳しくは第5章）

PHP
$user = ["name" => "Alice", "age" => 20];
TS
const user = { name: "Alice", age: 20 };

値を取り出す

普段は . を使う

PHP
$user["name"]
TS
user.name/user["name"]

値を変える

オブジェクトを代入したときの動きは第4章

PHP
$user["age"] = 21;
TS
user.age = 21;

キーがあるか

"toString" のように元からある名前でも true になる

PHP
array_key_exists("name", $user)
TS
"name" in user

キーと値を順に

Object.entries はキーと値の組の配列を返す。[k, v] の書き方は第4章 4.2

PHP
foreach ($user as $k => $v) { }
TS
for (const [k, v] of Object.entries(user)) { }

キーが自由な辞書

PHP
$count["食費"] = 1000;
TS
Map（第8章）か Record（第5章）

1.8 例外

例外を投げる

クラス名が Error

PHP
throw new Exception("失敗");
TS
throw new Error("失敗");

受け取る

受け取る型は書かない。e は何が来るか分からない型（第9章）

PHP
try { } catch (Exception $e) { }
TS
try { } catch (e) { }

メッセージ

第9章で絞り込んでから使う

PHP
$e->getMessage()
TS
e.message

1.9 クラス

クラスは読めれば十分です。自分で書く場面はほとんどなく、new Map() や new Error("失敗") のように用意されたクラスを使うときに出てきます。

クラスを作る

プロパティは $ なしで、型を後ろに書く

PHP
class User { private string $name; ... }
TS
class User { private name: string; ... }

コンストラクタ

PHP
public function __construct(string $name) {
$this->name = $name;
}
TS
constructor(name: string) {
this.name = name;
}

メソッド

function は付けない。$this-> は this.

PHP
public function greet(): string {
return "Hi " . $this->name;
}
TS
greet(): string {
return "Hi " + this.name;
}

使う

-> は .

PHP
$u = new User("Alice"); $u->greet();
TS
const u = new User("Alice"); u.greet();

継承する

同じ書き方。Admin は User のプロパティとメソッドをすべて持つ

PHP
class Admin extends User { ... }
TS
class Admin extends User { ... }

そのクラスのオブジェクトかを確かめる

同じ書き方。Admin のオブジェクトも true になる

PHP
$u instanceof User
TS
u instanceof User

1.10 ファイルを分ける

他のファイルで使えるようにする

export を付けたものだけ外から使える（第8章）

PHP
（何もしなくてよい）
TS
export function add(...) { }

他のファイルのものを使う

第8章

PHP
require "math.php";
TS
import { add } from "./math.ts";
