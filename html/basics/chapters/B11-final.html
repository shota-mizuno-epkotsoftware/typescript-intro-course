11.1 課題の進め方

家計簿の記録を題材にした演習が 5 つあります。

  • これまでの演習と違い、書き出しはありません。 演習 1〜4 には進め方の手順もありません。ヒントには、見返す章を挙げています。
  • 演習 5 には、表示する行の順に、途中で実行して確かめる手順があります。各手順で何を書くかは、自分で考えます。
  • 11.2 の書き方の一覧は、演習の途中で見返して構いません。
  • 11.3 から後は、演習の後で読みます。
演習 すること 答え合わせが調べるもの
1 間違いのあるプログラムを直す 実行したときの表示
2〜4 関数を 1 つずつ書く 関数が返す値
5 集計を表示するプログラムを最初から書く 実行したときの表示

記録は、日付・カテゴリ・金額を持つオブジェクトです。表の entries は、次の配列です。

const entries = [
  { date: "2026-04-01", category: "食費", amount: 1200 },
  { date: "2026-04-03", category: "交通費", amount: 480 },
  { date: "2026-04-05", category: "食費", amount: 3500 },
  { date: "2026-04-10", category: "趣味", amount: 2800 },
];

演習のファイルは、basics/exercises/B11-final/practice-01.js から practice-05.js までの 5 つです。

  • 演習ごとに npm test B11 practice-01 の形で答え合わせします。演習 1 合格 と出れば、その演習は完了です。
  • 演習 2〜4 のファイルには、同じ配列が sample という名前で入っています。関数を試すときは、ファイルのいちばん下に console.log(toLines(sample)); のような行を足して、node で実行します。
  • この章の演習では、別のファイルの関数を使いません。同じ計算が要るときは、今書いている関数の中にもう一度書きます。
  • 演習 1 と演習 5 の先頭の変数は、値を変えて試したら、答え合わせの前に元に戻します（第2章の演習の前の決まりと同じ）。entries の中身は書き換えません。

うまく動かないときは、関数の中に console.log を足して値を追います（第3章の 3.4）。

うまくいかないとき（演習 2〜4 で共通）
表示 よくある原因
「実際の値」が undefined か [ undefined, undefined, ... ] 関数が値を返していません。配列の場合は、map に渡した関数です。{ } の中から値を返すときは、return を書きます
「実際の値」に NaN、undefined、[object Object] が混ざる entries.amount のように、配列からプロパティを取り出そうとしているか、オブジェクトをそのまま足しています。プロパティは、1 件の記録から取り出します
演習 3 で、最初の記録がそのまま返る 比べる式で、entries.amount と書いているか、オブジェクトの max と比べています。比べるのは、1 件の記録の amount と max.amount です
記録を変えた検査でも、同じ結果が返る 引数の entries ではなく、sample を使っています
Cannot read properties of undefined (reading 'amount') 空の配列を渡した検査で、entries[0].amount を取り出しています。「場所: practice-03.js の 15 行目」のような行を見ます
「期待した値」と 1 文字だけ違う文字列 空白や「円」の違いです。1 文字ずつ見比べます

演習 1：間違いを直す

basics/exercises/B11-final/practice-01.js は、食費の合計と記録の件数を表示するプログラムです。間違いが 3 つあります。2 つはエラーになり、1 つはエラーにならず表示が違います。直して、次のように表示させます。

食費: 4700円
記録: 4件
食費は予算の半分以内です

食費の合計と件数は、4700 や 4 と直接書かずに、計算で求める形のままにします。node basics/exercises/B11-final/practice-01.js で実行し、エラーと表示を読んで直します。

第3章（エラーの読み方、エラーが出ないのに結果が違うとき）、第2章（const と let）、第5章（配列の要素の数）

演習 2：記録を文字列にする

toLines(entries) は、記録を 1 件ずつ「日付 カテゴリ 金額円」の形の文字列に変えて、その配列を返します。日付とカテゴリの後ろには、半角の空白を 1 つ入れます。金額と「円」の間には、空白を入れません。

呼び出し 返す値
toLines(entries) ["2026-04-01 食費 1200円", "2026-04-03 交通費 480円", "2026-04-05 食費 3500円", "2026-04-10 趣味 2800円"]
toLines([]) []

答え合わせは、表にない記録でも検査します。

// 基礎編 第11章 演習 2: 記録を文字列にする
// 記録の配列 entries を、「日付 カテゴリ 金額円」の形の文字列の配列にして返す。
// 例: { date: "2026-04-01", category: "食費", amount: 1200 } は "2026-04-01 食費 1200円"

// 試すためのデータです。書き換えて構いません
const sample = [
  { date: "2026-04-01", category: "食費", amount: 1200 },

  { date: "2026-04-05", category: "食費", amount: 3500 },
  { date: "2026-04-10", category: "趣味", amount: 2800 },
];

export function toLines(entries) {
  return entries.map((entry) => `${entry.date} ${entry.category} ${entry.amount}円`);
}

basics/solutions/B11-final/practice-03.js

// 基礎編 第11章 演習 3: いちばん大きい支出を探す
// 記録の配列 entries のうち、金額がいちばん大きい記録（オブジェクト）を返す。
// 空の配列なら undefined を返す。

// 試すためのデータです。書き換えて構いません
const sample = [
  { date: "2026-04-01", category: "食費", amount: 1200 },
  { date: "2026-04-03", category: "交通費", amount: 480 },
  { date: "2026-04-05", category: "食費", amount: 3500 },
  { date: "2026-04-10", category: "趣味", amount: 2800 },
];

export function largest(entries) {
  let result = entries[0];
  for (const entry of entries) {
    if (entry.amount > result.amount) {
      result = entry;
    }
  }
  return result;
}

演習 4：予算と比べる

budgetReport(entries, budget) は、金額の合計を予算 budget と比べて、結果を文字列で返します。合計が予算とちょうど同じときは、「残り 0円」です。

呼び出し 返す値
budgetReport(entries, 10000) "合計 7980円（残り 2020円）"
budgetReport(entries, 5000) "合計 7980円（2980円の予算オーバー）"
budgetReport(entries, 7980) "合計 7980円（残り 0円）"
budgetReport([], 3000) "合計 0円（残り 3000円）"

「合計」と「残り」の後ろには、半角の空白を 1 つ入れます。かっこは、全角の （ ） です。答え合わせは、表にない記録でも検査します。

ヒント：見返す章

第5章の 5.4（合計する形）、第8章（オブジェクトの配列）、第4章（if と比較）、第6章の 6.4（return で関数が終わること）

解答例を見る

basics/solutions/B11-final/practice-04.js

// 基礎編 第11章 演習 4: 予算と比べる
// 記録の配列 entries の合計を、予算 budget と比べた結果の文字列を返す。
// 合計が予算以下なら「合計 7980円（残り 2020円）」の形、
// 予算を超えていたら「合計 7980円（2980円の予算オーバー）」の形にする。

// 試すためのデータです。書き換えて構いません
const sample = [
  { date: "2026-04-01", category: "食費", amount: 1200 },
  { date: "2026-04-03", category: "交通費", amount: 480 },
  { date: "2026-04-05", category: "食費", amount: 3500 },
  { date: "2026-04-10", category: "趣味", amount: 2800 },
];

export function budgetReport(entries, budget) {
  let total = 0;
  for (const entry of entries) {
    total += entry.amount;
  }
  if (total <= budget) {
    return `合計 ${total}円（残り ${budget - total}円）`;
  }
  return `合計 ${total}円（${total - budget}円の予算オーバー）`;
}

演習 5：家計簿の集計を表示する

最後は、関数ではなくプログラムを 1 つ書きます。basics/exercises/B11-final/practice-05.js には、予算などの変数と記録の配列が書いてあります。その下に、集計して表示するプログラムを書きます。書く量は 30〜40 行ほどです。

表示の例

食費: 4700円
交通費: 480円
趣味: 2800円
合計: 7980円
残り: 2020円
大きな支出（2000円以上）: 2件
2026-04-05 食費 3500円
2026-04-10 趣味 2800円
行 表示するもの
1〜3 行目 categories のカテゴリごとの合計。categories に並んでいる順に、1 行ずつ
4 行目 全部の記録の合計。categories にないカテゴリの記録も含める
5 行目 合計が budget 以下なら 残り: 2020円 の形、超えていたら 予算オーバー: 980円 の形
6 行目 金額が limit 以上の記録の件数。2000 の所には、limit の値が入る
7 行目から 金額が limit 以上の記録を、1 件ずつ「日付 カテゴリ 金額円」の形で

行の番号は、表示の例のものです。categories のカテゴリの数が変わると、4 行目から後の位置もずれます。

: の後ろと、日付とカテゴリの後ろには、半角の空白を 1 つ入れます。かっこは、全角の （ ） です。

守ること

  • 名前を付けた関数（function 名前(...)、または const 名前 = (...) =>）を 2 つ以上作り、それを呼んで計算する。filter や map に渡す関数は、数に入りません。
  • 金額が limit 以上の記録は、filter を使わずに、空の配列を用意して push で集める（第5章の 5.4 の集める形）。答え合わせは、push を使っているかを調べます。
  • 答え合わせは、budget、limit、categories の値を変えた場合も検査します。

進め方

  1. カテゴリを 1 つ受け取って、そのカテゴリの合計を返す関数を作り、"食費" で呼んで表示する

    • 1 つのカテゴリの金額を合計する形は、第8章の問題 2 です
    node basics/exercises/B11-final/practice-05.js
    • こうなれば OK4700 と表示される

  2. 試した表示の行を消し、categories を for...of で繰り返して、1〜3 行目を表示する

    • 繰り返しの中で、取り出したカテゴリを 1 で作った関数に渡します
    node basics/exercises/B11-final/practice-05.js
    • こうなれば OK表示の例の 1〜3 行目と同じになる

  3. 全部の記録の合計を求めて、4 行目と 5 行目を表示する

    • 名前を付けた関数は、2 つ以上要ります（守ることの 1 つ目）。まだ 1 つなら、全部の記録の合計も関数にして呼びます
    node basics/exercises/B11-final/practice-05.js
    • こうなれば OK表示の例の 1〜5 行目と同じになる

    • 「以上」は >= です。> だと、limit と同じ金額の記録が数えられません。表示の例のデータには、そのような記録がないので、表示では気づけません

// 基礎編 第11章 演習 5: 家計簿の集計を表示する
// 下のデータを集計して、本文の「表示の例」と同じ形で表示するプログラムを書いてください。
// budget、limit、categories の行は、値を変えて試したら、元に戻します。entries の中身は、書き換えません。

const budget = 10000; // 今月の予算
const limit = 2000; // この金額以上の記録を「大きな支出」とする
const categories = ["食費", "交通費", "趣味"]; // 集計するカテゴリ

const entries = [
  { date: "2026-04-01", category: "食費", amount: 1200 },
  { date: "2026-04-03", category: "交通費", amount: 480 },
  { date: "2026-04-05", category: "食費", amount: 3500 },
  { date: "2026-04-10", category: "趣味", amount: 2800 },
];

// ここから下に書く
function totalOf(list, category) {
  let total = 0;
  for (const entry of list) {
    if (entry.category === category) {
      total += entry.amount;
    }
  }
  return total;
}

function totalAmount(list) {
  let total = 0;
  for (const entry of list) {
    total += entry.amount;
  }
  return total;
}

for (const category of categories) {
  console.log(`${category}: ${totalOf(entries, category)}円`);
}

const total = totalAmount(entries);
console.log(`合計: ${total}円`);
if (total <= budget) {
  console.log(`残り: ${budget - total}円`);
} else {
  console.log(`予算オーバー: ${total - budget}円`);
}

const large = [];
for (const entry of entries) {
  if (entry.amount >= limit) {
    large.push(entry);
  }
}
console.log(`大きな支出（${limit}円以上）: ${large.length}件`);
for (const entry of large) {
  console.log(`${entry.date} ${entry.category} ${entry.amount}円`);
}

11.3 扱わなかった書き方

ほかの人が書いたコードでは、基礎編で扱わなかった書き方も出てきます。名前と意味を知っておくと、調べる手がかりになります。

書き方 意味
'こんにちは' ' で囲んだ文字列。" で囲んだものと同じ
var total = 0; 変数を宣言する、古い書き方。今は const と let を使う
a == b、a != b 値の種類が違うと、自動で変えてから比べる。思わぬ結果になるので、=== と !== を使う
a % b a を b で割った余り
条件 ? a : b 条件が true なら a、false なら b
while (条件) { ... } 条件が true の間、繰り返す
prices.reduce(...)、prices.sort(...) 配列を 1 つの値にまとめる、並べ替える
const { amount } = entry; 分割代入。オブジェクトのプロパティを、同じ名前の変数に取り出す
[...prices, 50] スプレッド構文。配列の中身を並べて、新しい配列を作る
a ?? b a が null か undefined なら b、そうでなければ a
switch (値) { case ...: } 値によって、行う処理を分ける。一致した case から下へ実行するので、各 case の終わりに break（switch を抜ける）を書く
throw new Error("メッセージ") エラーを投げて、そこで処理を止める
try { ... } catch (error) { ... } エラーが起きたときの処理を書く
class Entry { ... } クラス。オブジェクトのひな形を作る
new Entry()、new Error("…") クラスから、新しいオブジェクトを作る
値 instanceof Error 値が、そのクラスから作られたオブジェクトなら true
async、await async を付けた関数の中で、await を付けた処理（通信など）の結果を待つ

import と export は、演習のファイルに出てきましたが、くわしくは説明していません。import は別のファイルの関数や値を使う書き方、export はそれを使えるようにする書き方です。本編 第8章で扱います。

11.4 本編へ進む人へ

基礎編に続く本編では、TypeScript を学びます。TypeScript は、JavaScript に型（値の種類の決まり）を書き足した言語です。基礎編で書いたコードは、ほぼそのまま TypeScript でも動きます。

"100" + 20 が 10020 になったように、JavaScript は、値の種類が思っていたものと違っても、そのまま実行することがあります。TypeScript では、「この変数は数値」と書いておくと、文字列を入れたときに、実行する前にエディタが間違いを知らせます。

本編に進む前に、次の 3 つを知っておいてください。

  • 本文の「PHPでは」のコラムは、PHP の書き方を思い出せなければ、読み飛ばして構いません。本編は、PHP との違いを軸に説明します。
  • 本編の 第1章 基本文法の対応表 は、PHP の列があやふやなら、読まなくて構いません。代わりに、11.2 の「書き方の一覧」を使います。TypeScript の列に知らない書き方があれば、11.3 と見比べます。
  • 本編では、章を終えるごとに、演習の変更を Git でコミットします。やり方は本編 第0章の 0.7 にあります。

本編は、第0章 環境構築 の 0.3 から始めます。道具と教材の準備は済んでいて、基礎編と同じ TSLecture フォルダで進めます。
