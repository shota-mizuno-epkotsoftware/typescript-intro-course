## 11.1 課題の進め方

家計簿の記録を題材にした演習が 5 つあります。

- これまでの演習と違い、**書き出しはありません。** 演習 1〜4 には進め方の手順もありません。ヒントには、見返す章を挙げています。
- 演習 5 には、表示する行の順に、途中で実行して確かめる手順があります。各手順で何を書くかは、自分で考えます。
- 11.2 の書き方の一覧は、演習の途中で見返して構いません。
- 11.3 から後は、演習の後で読みます。

| 演習 | すること | 答え合わせが調べるもの |
| --- | --- | --- |
| 1 | 間違いのあるプログラムを直す | 実行したときの表示 |
| 2〜4 | 関数を 1 つずつ書く | 関数が返す値 |
| 5 | 集計を表示するプログラムを最初から書く | 実行したときの表示 |

記録は、日付・カテゴリ・金額を持つオブジェクトです。表の `entries` は、次の配列です。

```js
  { date: "2026-04-03", category: "交通費", amount: 480 },
  { date: "2026-04-05", category: "食費", amount: 3500 },
  { date: "2026-04-10", category: "趣味", amount: 2800 },
];
```

演習のファイルは、`basics/exercises/B11-final/practice-01.js` から `practice-05.js` までの 5 つです。

- 演習ごとに `npm test B11 practice-01` の形で答え合わせします。`演習 1  合格` と出れば、その演習は完了です。
- 演習 2〜4 のファイルには、同じ配列が `sample` という名前で入っています。関数を試すときは、ファイルのいちばん下に `console.log(toLines(sample));` のような行を足して、`node` で実行します。
- この章の演習では、別のファイルの関数を使いません。同じ計算が要るときは、今書いている関数の中にもう一度書きます。
- 演習 1 と演習 5 の先頭の変数は、値を変えて試したら、答え合わせの前に元に戻します（第2章の演習の前の決まりと同じ）。`entries` の中身は書き換えません。

## 演習 5：家計簿の集計を表示する

最後は、関数ではなくプログラムを 1 つ書きます。`basics/exercises/B11-final/practice-05.js` には、予算などの変数と記録の配列が書いてあります。その下に、集計して表示するプログラムを書きます。書く量は 30〜40 行ほどです。

**表示の例**

```
食費: 4700円
交通費: 480円
趣味: 2800円
合計: 7980円
残り: 2020円
大きな支出（2000円以上）: 2件
2026-04-05 食費 3500円
2026-04-10 趣味 2800円
```

| 行 | 表示するもの |
| --- | --- |
| 1〜3 行目 | `categories` のカテゴリごとの合計。`categories` に並んでいる順に、1 行ずつ |
| 4 行目 | 全部の記録の合計。`categories` にないカテゴリの記録も含める |
| 5 行目 | 合計が `budget` 以下なら `残り: 2020円` の形、超えていたら `予算オーバー: 980円` の形 |
| 6 行目 | 金額が `limit` 以上の記録の件数。`2000` の所には、`limit` の値が入る |
| 7 行目から | 金額が `limit` 以上の記録を、1 件ずつ「日付 カテゴリ 金額円」の形で |

行の番号は、表示の例のものです。`categories` のカテゴリの数が変わると、4 行目から後の位置もずれます。

`:` の後ろと、日付とカテゴリの後ろには、半角の空白を 1 つ入れます。かっこは、全角の `（` `）` です。

**守ること**

- 名前を付けた関数（`function 名前(...)`、または `const 名前 = (...) =>`）を 2 つ以上作り、それを呼んで計算する。`filter` や `map` に渡す関数は、数に入りません。
- 金額が `limit` 以上の記録は、`filter` を使わずに、空の配列を用意して `push` で集める（第5章の 5.4 の集める形）。答え合わせは、`push` を使っているかを調べます。
- 答え合わせは、`budget`、`limit`、`categories` の値を変えた場合も検査します。

**進め方**

1. カテゴリを 1 つ受け取って、そのカテゴリの合計を返す関数を作り、`"食費"` で呼んで表示する
   - 1 つのカテゴリの金額を合計する形は、第8章の問題 2 です
   ```sh
   node basics/exercises/B11-final/practice-05.js
   ```
   - **こうなれば OK**：`4700` と表示される
2. 試した表示の行を消し、`categories` を `for...of` で繰り返して、1〜3 行目を表示する
   - 繰り返しの中で、取り出したカテゴリを 1 で作った関数に渡します
   ```sh
   node basics/exercises/B11-final/practice-05.js
   ```
   - **こうなれば OK**：表示の例の 1〜3 行目と同じになる
3. 全部の記録の合計を求めて、4 行目と 5 行目を表示する
   - 名前を付けた関数は、2 つ以上要ります（守ることの 1 つ目）。まだ 1 つなら、全部の記録の合計も関数にして呼びます
   ```sh
   node basics/exercises/B11-final/practice-05.js
   ```
   - **こうなれば OK**：表示の例の 1〜5 行目と同じになる
4. 金額が `limit` 以上の記録を空の配列に集めて、6 行目から後を表示する
   - 「以上」は `>=` です。`>` だと、`limit` と同じ金額の記録が数えられません。表示の例のデータには、そのような記録がないので、表示では気づけません
   ```sh
   node basics/exercises/B11-final/practice-05.js
   ```
   - **こうなれば OK**：表示の例と同じになる
5. 答え合わせをする
   ```sh
   npm test B11
   ```
   - **こうなれば OK**：`結果: この章の演習は、すべて合格です。` と表示される

## 11.2 書き方の一覧

基礎編で習った書き方の一覧です。覚える必要はありません。書き方を思い出せないときに見返します。

### 値と計算（第1章）

| 書き方 | 意味 |
| --- | --- |
| `120`、`3.5` | 数値 |
| `"こんにちは"` | 文字列 |
| `+` `-` `*` `/` | 足す、引く、掛ける、割る。`*` と `/` が先に計算される |
| `(2 + 3) * 4` | `( )` の中が先に計算される |
| `"合計: " + 200` | 文字列に `+` を使うと、つなぐ |
| `` `合計: ${price * 2}円` `` | テンプレート文字列。`${ }` の中の式の結果が入る |
| `console.log(値);` | 値を表示する |
| `// メモ` | コメント。実行されない |

### 変数（第2章）

| 書き方 | 意味 |
| --- | --- |
| `const price = 120;` | 変数を宣言する。入れ直せない |
| `let total = 0;` | 変数を宣言する。入れ直せる |
| `total = total + 50;` | 今の値を使って入れ直す |
| `total += 50;`、`total -= 30;` | 今の値に足す、今の値から引く |

### エラー（第3章）

説明ごとの意味は、第3章の「エラーの早見表」にあります。

| エラーの種類 | 意味 |
| --- | --- |
| `SyntaxError` | 書き方の決まりに合わない。1 行も実行されない |
| `ReferenceError` | その名前のものを、その時点では使えない |
| `TypeError` | 値の使い方が合わない |

### 条件分岐（第4章）

| 書き方 | 意味 |
| --- | --- |
| `true`、`false` | 真偽値 |
| `a === b`、`a !== b` | 同じ、違う |
| `a > b`、`a >= b`、`a < b`、`a <= b` | 大きい、以上、小さい、以下 |
| `if (条件) { ... }` | 条件が `true` のときだけ実行する |
| `if (条件) { ... } else { ... }` | 条件が `false` のときは、`else` の中を実行する |
| `else if (条件) { ... }` | 上の条件が `false` だったときに、次の条件を調べる |
| `a && b`、`a \|\| b`、`!a` | 「かつ」「または」「ではない」 |

### 配列と繰り返し（第5章）

| 書き方 | 意味 |
| --- | --- |
| `const prices = [120, 80, 300];` | 配列を作る。`[]` は空の配列 |
| `prices[0]` | 最初の要素。番号は 0 から |
| `prices[0] = 150;` | 要素を入れ直す |
| `prices.length` | 要素の数 |
| `prices.push(50);` | 最後に要素を足す |
| `for (const price of prices) { ... }` | 要素を 1 つずつ取り出して繰り返す |
| `for (let i = 0; i < prices.length; i++) { ... }` | 番号 `i` を 0 から 1 ずつ増やしながら繰り返す。`i++` は `i` を 1 増やす（5.6） |
| `let max = prices[0];` の後、繰り返しの中で `if (price > max) { max = price; }` | いちばん大きい値を探す形。最初の要素から始めて、大きい要素が出たら入れ直す |
| `const result = [];` の後、繰り返しの中で `if (price >= 1000) { result.push(price); }` | 集める形。空の配列に、条件に合う要素を足す |

### 関数（第6章、第7章）

| 書き方 | 意味 |
| --- | --- |
| `function double(n) { return n * 2; }` | 関数を作る。`n` は引数 |
| `double(5)` | 関数を呼ぶ。この式は、戻り値の `10` に置き換わる |
| `return 値;` | 値を返して関数を終わる |
| `const double = (n) => n * 2;` | アロー関数。`=>` の右の式の結果が戻り値 |
| `const double = (n) => { return n * 2; };` | アロー関数。`{ }` の中から値を返すときは、`return` を書く |
| `double` と `double(5)` | `( )` がなければ関数そのもの、あれば呼んだ結果 |

### オブジェクト（第8章）

| 書き方 | 意味 |
| --- | --- |
| `const entry = { category: "食費", amount: 1200 };` | オブジェクトを作る |
| `entry.amount` | プロパティの値を取り出す |
| `entry.amount = 1500;` | プロパティの値を入れ直す |
| `entry.memo = "昼食";` | ない名前に代入すると、プロパティが足される |
| `entries[0].amount` | 配列の最初のオブジェクトの `amount` |
| `month.entries[0].amount` | 入れ子。左から順にたどる |

### 配列のメソッド（第9章）

| 書き方 | 意味 |
| --- | --- |
| `prices.map((price) => price * 2)` | 要素を 1 つずつ変換した、新しい配列を返す |
| `prices.filter((price) => price >= 100)` | 条件に合う要素だけの、新しい配列を返す |
| `prices.find((price) => price >= 100)` | 条件に合う最初の要素を返す |
| `prices.filter(...).map(...)` | メソッドをつなげる。左から順に実行される |
| `prices.map(double)` | 関数は値なので、引数で渡せる。渡す関数をコールバックと呼ぶ |
| `text \|\| "なし"`、`found && found.amount` | `\|\|` と `&&` の結果は、左右のどちらかの値（第9章のコラム） |

### 画面（第10章）

| 書き方 | 意味 |
| --- | --- |
| `document.querySelector("#message")` | その `id` の要素を取る |
| `message.textContent = "こんにちは";` | 要素の文字を変える |
| `button.addEventListener("click", () => { ... });` | クリックされたときに、関数を実行する |
| `amount.value` | 入力欄の値。数字を打っても文字列 |
| `Number("100")` | 文字列を数値に変える |
| `Number.isNaN(値)` | `NaN` かどうかを調べる |

### 「ない」や「計算できない」を表す値

| 値 | 出てくる場面 |
| --- | --- |
| `undefined` | 配列にない番号の要素、オブジェクトにない名前のプロパティ、値を渡さなかった引数、`return` のない関数の戻り値、`find` で見つからなかったとき |
| `NaN` | 数値として計算できなかったとき。`undefined` に数を足したときや、`Number("abc")` |
| `null` | `querySelector` で要素が見つからなかったとき |

## 11.3 扱わなかった書き方

ほかの人が書いたコードでは、基礎編で扱わなかった書き方も出てきます。名前と意味を知っておくと、調べる手がかりになります。

| 書き方 | 意味 |
| --- | --- |
| `'こんにちは'` | `'` で囲んだ文字列。`"` で囲んだものと同じ |
| `var total = 0;` | 変数を宣言する、古い書き方。今は `const` と `let` を使う |
| `a == b`、`a != b` | 値の種類が違うと、自動で変えてから比べる。思わぬ結果になるので、`===` と `!==` を使う |
| `a % b` | `a` を `b` で割った余り |
| `条件 ? a : b` | 条件が `true` なら `a`、`false` なら `b` |
| `while (条件) { ... }` | 条件が `true` の間、繰り返す |
| `prices.reduce(...)`、`prices.sort(...)` | 配列を 1 つの値にまとめる、並べ替える |
| `const { amount } = entry;` | 分割代入。オブジェクトのプロパティを、同じ名前の変数に取り出す |
| `[...prices, 50]` | スプレッド構文。配列の中身を並べて、新しい配列を作る |
| `a ?? b` | `a` が `null` か `undefined` なら `b`、そうでなければ `a` |
| `switch (値) { case ...: }` | 値によって、行う処理を分ける。一致した `case` から下へ実行するので、各 `case` の終わりに `break`（`switch` を抜ける）を書く |
| `throw new Error("メッセージ")` | エラーを投げて、そこで処理を止める |
| `try { ... } catch (error) { ... }` | エラーが起きたときの処理を書く |
| `class Entry { ... }` | クラス。オブジェクトのひな形を作る |
| `new Entry()`、`new Error("…")` | クラスから、新しいオブジェクトを作る |
| `値 instanceof Error` | 値が、そのクラスから作られたオブジェクトなら `true` |
| `async`、`await` | `async` を付けた関数の中で、`await` を付けた処理（通信など）の結果を待つ |

`import` と `export` は、演習のファイルに出てきましたが、くわしくは説明していません。`import` は別のファイルの関数や値を使う書き方、`export` はそれを使えるようにする書き方です。本編 第8章で扱います。

## 11.4 本編へ進む人へ

基礎編に続く本編では、**TypeScript** を学びます。TypeScript は、JavaScript に**型**（値の種類の決まり）を書き足した言語です。基礎編で書いたコードは、ほぼそのまま TypeScript でも動きます。

`"100" + 20` が `10020` になったように、JavaScript は、値の種類が思っていたものと違っても、そのまま実行することがあります。TypeScript では、「この変数は数値」と書いておくと、文字列を入れたときに、実行する前にエディタが間違いを知らせます。

本編に進む前に、次の 3 つを知っておいてください。

- 本文の「PHPでは」のコラムは、PHP の書き方を思い出せなければ、読み飛ばして構いません。本編は、PHP との違いを軸に説明します。
- 本編の [第1章 基本文法の対応表](../../main/chapters/M01-syntax-table.md) は、PHP の列があやふやなら、読まなくて構いません。代わりに、11.2 の「書き方の一覧」を使います。TypeScript の列に知らない書き方があれば、11.3 と見比べます。
- 本編では、章を終えるごとに、演習の変更を Git でコミットします。やり方は本編 第0章の 0.7 にあります。

本編は、[第0章 環境構築](../../main/chapters/M00-setup.md) の 0.3 から始めます。道具と教材の準備は済んでいて、基礎編と同じ `TSLecture` フォルダで進めます。
